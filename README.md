# Trendline Precision

MASTER WEBSITE PROMPT

Create a premium, modern, one-page sales website for a luxury trading education brand called Trendline Precision.

The website is designed to sell a premium trading book priced at $55.

The visual style should combine the elegance of Apple, Stripe, Bloomberg, TradingView, and a high-end online education company.

The design should be realistic, luxurious, trustworthy, minimal, and extremely clean.

Avoid anything that looks like a typical "forex guru" website.

No Lamborghinis.

No stacks of cash.

No private jets.

No fake account balances.

No exaggerated profit claims.

No neon green/red designs.

Use a sophisticated color palette:

Matte black

Deep navy

Metallic gold

White

Soft gray

The homepage should be built in sections.

SECTION 1 — HERO

Split layout.

LEFT SIDE

Display multiple premium book mockups.

One hardcover book standing upright.

One slightly angled paperback.

One tablet displaying the PDF version.

One phone showing a page from inside the book.

Everything should look like a premium educational product.

Behind the products, display a subtle TradingView-style chart with clean trendlines and price action.

RIGHT SIDE

Large headline:

STOP GUESSING THE MARKET.

START READING IT.

Subheadline:

Master price action, trendlines, market structure, and disciplined trading through one complete professional trading system.

Immediately underneath, create a premium "Challenge" box.

Title:

The Trendline Precision Challenge

The box should explain that readers can try the educational system with confidence.

Include a prominent satisfaction guarantee area with space for the site's final guarantee wording (do not state or imply guaranteed trading profits).

Style the box with a gold border and premium badge.

Below the challenge box place three large buttons:

BUY THE BOOK

SEE STUDENT RESULTS

SEE WHAT YOU'LL LEARN
